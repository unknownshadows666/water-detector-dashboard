The system automatically monitors water levels in real time using an analog sensor module and an ESP8266 microcontroller. When water crosses a calibrated safety limit, it triggers a local 1000Hz continuous audio alarm and transmits a push notification to a mobile device via the Blynk cloud platform.

The NodeMCU incorporates built-in 2.4GHz 802.11 b/g/n Wi-Fi on a single compact chip at a low cost, enabling direct IoT cloud communication without needing additional network shields.

The sensor features exposed parallel copper traces. As water rises across the board, the conductive liquid bridge lowers the electrical resistance between traces, allowing more current to flow and producing a higher output voltage.

The ESP8266 has a single 10-bit Analog-to-Digital Converter (ADC), yielding integer values from 0 (0V) to 1023 (maximum reference voltage).

Pin A0 is the only analog input pin on the NodeMCU board, making it the required interface for reading continuously variable voltage signals generated by the sensor.

Pin D5 (GPIO 14) is a standard general-purpose input/output (GPIO) pin supporting Pulse Width Modulation (PWM), suitable for driving active or passive audio transducers without interfering with boot sequences.

Pins labeled S1, S2, SK, SC, SO, and SI connect directly to the onboard SPI flash memory holding the firmware code. Reassigning them causes immediate system crashes and Watchdog Timer resets.

The threshold is calibrated to 620 ADC units. This value was established through empirical testing by sampling dry ambient states versus the target water level using real-time serial telemetry.

The firmware executes a 10-sample moving average filter on pin A0 before comparing the reading to the threshold, suppressing temporary liquid sloshing or electrical noise spikes.

Because a passive buzzer lacks an integrated oscillator, the microcontroller uses the tone(buzzerPin, 1000) function to generate a 1000Hz square wave signal, while noTone(buzzerPin) silences it.

A non-blocking time-gate implemented with millis() enforces a 30-second interval between cloud event logs, preventing network flooding during sustained high water levels.

The Auth Token serves as an encrypted API credential that authenticates the NodeMCU board with the designated device instance on the Blynk 2.0 Cloud platform.

Local safeguard monitoring runs independently on the microcontroller loop. If Wi-Fi fails, cloud logging pauses, but the local buzzer still sounds immediately upon threshold breach.

While the raw ESP8266 IC takes up to 1.0V, the NodeMCU development board contains an internal 220k/100k voltage divider on pin A0, allowing safe input up to 3.3V.
